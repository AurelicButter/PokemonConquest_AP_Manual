# Pokemon Conquest Manual

A manual for [Archipelago](https://archipelago.gg) made to use with Pokemon Conquest, a game released on the Nintendo DS.

## Progression
The goal of the manual is to clear The Legend of Ransei story line, which is to conquer all 17 kingdoms, stop Nobunga, and meet Arceus. The starting kingdom of Aurora and Ignis are provided at the start but to unlock further kingdoms, you'll be required to find the kingdom keys.

## Options
All options are currently toggleable with true/false. This is a very early build so please see the lists below of what is stable and what isn't.

Stable options:
- Progressive key toggle (True enables progressive keys while false enables kingdom specific keys)
- Duelsanity (Adds extra checks for defeating enemies during the kingdom battles, will add more filler items to the item pool)
- Locationsanity (Ability to add the various shops and training grounds into the item pool)

Unstable options:
- Warriorsanity (Ability to add warrior units to the item pool)
    - Unstable since it keeps putting early game warriors into the late game.
- Itemsanity (Ability to add the game's items into the item pool)
    - Unstable as I'm still working out the item specifics for better generation.
